# Recursos del Curso de Arquitectura de Software

Bienvenido al repositorio principal de recursos para la materia de Arquitectura de Software.

## Descripción

Este repositorio sirve como el punto central para acceder a todos los materiales, actividades, ejercicios, y recursos adicionales utilizados durante el curso. Aquí encontrarás todo lo necesario para complementar tu aprendizaje y desarrollo en la materia.

## Contenido

A medida que avance el curso, este repositorio se irá poblando con:

*   **Actividades:** Guías, enunciados y rúbricas para las actividades prácticas y tareas.
*   **Recursos Teóricos:** Diapositivas, lecturas recomendadas, y enlaces a documentación relevante.
*   **Ejemplos de Código:** Proyectos de referencia, patrones de diseño implementados y fragmentos de código para ilustrar conceptos arquitectónicos.
*   **Talleres:** Material de apoyo para los talleres realizados en clase.

## Uso del Repositorio

Te recomendamos:
1.  Hacer un *fork* de este repositorio si deseas experimentar con los ejemplos.
2.  Mantener tu copia local actualizada (`git pull`) para acceder a los nuevos materiales publicados semana a semana.
